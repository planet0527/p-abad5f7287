GOODS STUDIO Ver.5

Ver.4からの追加：商品画像（縮小して端末保存）、バリエーション、セット販売（構成商品の在庫連動）。

GitHub Pagesで公開する場合：ZIPを展開し、index.html、sw.js、manifest.webmanifest、アイコン2点を同じフォルダにアップロード。HTTPSのURLでSafariから開き、設定タブのPWA準備状況を確認してください。

重要：Ver.4と同じ公開URL／同じブラウザなら保存済みデータを引き継ぐ設計です。公開場所を変えるとブラウザ保存データは引き継がれません。更新前に必ずJSONバックアップを取ってください。

セット商品は既存の商品を組み合わせて販売し、会計確定時に構成商品の在庫を減らします。セット構成を変更する場合はセットを削除して作り直してください。

画像はブラウザ保存容量を消費します。多数の画像登録は保存失敗の原因になります。端末ごとの保存であり、自動同期はありません。

オフライン動作・Safari実機は公開後に確認してください。

Ver.5.1: 起動・画像読み込み・JSON復元・CSV集計の進捗表示を追加。パーセントは処理段階または処理済み件数に基づきます。CSVダウンロードが端末に保存されたかどうかまでは検証できません。

Ver.6: 分析タブ（売上KPI、商品ランキング、時間帯別・日別売上、低在庫）と分析CSV出力を追加。過去の会計履歴に基づく売上であり、原価・利益計算は含みません。

Ver.7: バックアップ時刻、保存状況、練習モード、会計取消監査、現金照合、通信状態・データ説明を追加。最終バックアップ時刻はダウンロード操作開始の記録であり、保存完了の保証ではありません。

Ver.8: 検索・カテゴリ・お気に入り・お預かり金額候補・在庫増減と理由履歴・シンプル表示・スタッフ名・お客様表示・カート復元・オフライン準備確認。複数端末同期には未対応。端末ごとに独立した売上・在庫です。

Ver.9: 会計番号、返品返金記録、決済方法、履歴検索、締めレポート、原価経費概算利益、在庫しきい値、イベント比較、商品復元、表示設定、FAQ・フィードバックメモ、バックアップ検証を追加。
制限：自動クラウドバックアップ・端末間同期・外部決済の実行・税務上の正式な利益計算には非対応。返金は記録のみ。データ移行は旧形式をそのまま利用し、事前バックアップを推奨。公開前に実機検証必須。

Ver.10: 目的別設定カテゴリ、レジのクイック操作、会計金額の強調、タップ領域拡大、操作フィードバック、イベント切替時の未会計カート確認、警告表示の整理。
実機・本番利用前に会計、返品、CSV、JSONバックアップと復元、オフラインをテストしてください。複数端末同期はありません。

Ver.11 品質強化：販売時原価のスナップショット、返品後のランキング・時間帯・日別売上の整合、返品済み会計の取消防止、データ読み込み失敗時の上書き防止、保存失敗時のロールバック、イベント切替の失敗時復元、保存データ整合チェック、保存容量の目安、バックアップサイズ制限。
注意：旧バージョンで売った商品の原価は販売時点の値が保存されていないため、過去原価を完全には復元できません。保存データの自動クラウド同期・自動バックアップはありません。ブラウザの保存領域を消すと復旧できない場合があります。実運用前に必ずバックアップと復元を試してください。

Ver.12: 設定→アプリ設定→「このアプリについて」から製作者名「いろはしゆづき」、ポートフォリオ、サポート窓口準備中、更新履歴、データ保存・プライバシー説明を確認できます。
